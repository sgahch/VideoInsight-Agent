# 见影知著（VideoInsight Agent）— 5 分钟演示口播脚本

> 使用说明：[] 内为画面 / 动作提示，不念出。语速建议每分钟 220–260 字，总时长控制在 4 分 50 秒–5 分 10 秒。全程不出现院校、指导教师名称（双盲）。本脚本为 AI 辅助制作。

---

**[0:00–0:30] 开场：痛点 + 一句话定位**

你有没有这种经历——刷到一个两小时的干货视频，想把它变成自己的笔记，结果下载、转写、喂给大模型、再手动整理，折腾大半天？

我们做的「见影知著」，就是来解决这件事的。它的逻辑特别简单：**你粘贴一条视频链接，剩下的交给我们。** 几分钟后，你拿回一份带时间戳的逐字稿、一份结构化总结，还有观众评论和一个能追问的 AI 助手。

**[0:30–1:40] 演示一：粘贴链接即出结果**

现在我就现场演示。这是一条抖音上的技术分享视频——我把链接粘进来，选"总结"模式，点提交。

**[画面：浏览器操作，粘贴链接 → 提交 → 进度条开始走]**

注意看进度条，它不是装饰动画。我们的系统会读取真实运行的诊断数据，去学习转写速度的中位数和非转写开销，推算出真实的进度和剩余时间，还会自动过滤测试脏数据。大概一两分钟，结果就出来了。

**[画面：结果四视图：总结 / 逐字稿 / 评论 / JSON 切换展示]**

这是总结视图：核心要点、时间线、行动建议一目了然；切到逐字稿，每句话都带时间戳；评论视图里，我们把观众热评也一并抓了进来，喂给模型。

---

**[1:40–2:40] 演示二：AI 追问**

拿到结果只是第一步。我可以就这个视频继续问——"视频里提到的三个步骤分别是什么？"

**[画面：在追问框输入问题，模型基于该视频转写稿即时作答]**

模型只依据这段视频的内容回答，不会胡编。对学习者来说，这就等于把一个视频变成了一个随问随答的私人助教。

我们还支持本地上传——直接拖进视频文件就能分析，完全绕开平台风控，是最稳的主链路。

---

**[2:40–3:50] 创新点：我们到底新在哪**

很多人会问，这不就是接个大模型 API 吗？不是。我们的创新在**工程链路**上。

第一，**真实进度自学习校准**。进度条背后是历史诊断数据，系统动态学出转写速度中位数约 8 倍实时、非转写开销中位数约 81 秒，据此推算进度和 ETA，并自动过滤 Mock 脏数据——让进度从装饰变成可信信号。

第二，**抖音下载绕过签名墙**。通用的 yt-dlp 因为抖音强制 a_bogus 签名校验，到今年 8 月还普遍 403。我们改走移动分享页的 SSR 内嵌直链，不需要登录态、不需要签名，就能拿到无水印视频。

第三，**评论链和主链路解耦**。评论抓取失败只静默降级，绝不阻断下载和转写；抖音评论走内置直连接口，连爬虫都不用部署。

第四，**全链路自恢复**。长任务走有界线程池，进程重启自动对账、孤儿产物自动回收、可选鉴权默认拒绝——把"能跑一次"做成"能稳定服务"。

---

**[3:50–4:35] 价值与场景**

它能帮谁？求职者做面试复盘和面经提取；学生把课程和播客几分钟内变成摘要；创作者批量整理文案和脚本；企业把培训视频归档检索。

落地上我们以本地私有部署为主，隐私优先，原始音视频短期留存、可一键删除；也能叠加轻量 SaaS 按量计费。它的社会价值很朴素——降低优质视频知识的吸收门槛，让"看视频学习"可沉淀、可复用。
