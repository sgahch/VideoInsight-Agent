## VideoInsight Agent — 视频智能转写与结构化分析系统

> 编制说明：本报告基于项目现状（本科生、未注册公司、1 人主导技术开发）与《陕教高办〔2026〕13号》大赛文件逐条比对，给出主赛道推荐与备选方案，供报名决策使用。

## 一、结论速览（TL;DR）

| 决策项 | 建议 |

## 二、主赛道推荐：高教主赛道（本科创意组，"人工智能+"类）

### 2.1 匹配度逐条核查

| 大赛要求 | 本项目情况 | 匹配 |
|---|---|---|
| 面向普通高校在校本科生（2026年4月30日学籍为准） | 项目负责人为本科生 | ✅ |
| 团队 3—15 人，可跨校 | 当前 1 人主导，**需补齐至 3 人以上**（建议 3—5 人） | ⚠️ 需补 |
| "人工智能+"项目类型 | 本项目为"AI 音视频理解 + 多平台内容解析"工具，典型人工智能+应用 | ✅ 完全匹配 |
| 创意组：参赛项目具有较好的创意和较为成型的产品原型或服务模式，不要求工商注册 | 项目已完整实现（FastAPI 后端 + 沉浸式前端 + 真实 ASR/LLM 链路），产品原型成型 | ✅ 完美匹配 |
| 一人最多参与 1 个赛道 1 个项目 | 符合 | ✅ |
| 年龄 ≤35 岁 | 本科生符合 | ✅ |
| 商业计划书查重率 ≤25% | 需注意：技术文档与计划书建议原创撰写、避免大段引用网络内容 | ⚠️ 提交前需自查重 |

### 2.2 选择理由

1. **主赛道含金量与名额最高**：陕西赛区高教主赛道金奖约 170 项、银奖约 380 项、铜奖约 550 项，获奖面大；且奖项"向本科生倾斜"（文件原文），本科创意组是受益对象。
2. **晋级通道最优**：省赛冠军（主/红旅/职教最高分）直接晋级国赛现场赛；全国总决赛主赛道每校名额 ≤5 项，是各校主推方向，校赛资源倾斜明显。
3. **"人工智能+"类目是大赛政策风口**：通知明确六大赛道中高教主赛道含"人工智能+"五类之一，评审专家对该类项目预期充分、案例参照多，叙事成熟度要求可借鉴同类项目。

### 2.3 当前差距与补齐动作（9月5日前）

| 差距 | 补齐动作 |
|---|---|
| 团队不足 3 人 | 招募 2—4 名同校同学（建议 1 名负责商业/市场、1 名负责 UI/产品、1 名负责测试/数据），角色分工写入计划书 |
| 无指导老师 | 需 1 名指导教师（文件允许指导教师，但不允许教师作为团队成员参赛） |
| 商业计划书未成稿 | 使用本报告配套的《商业计划书框架》+《网评PPT大纲》成稿 |
| 查重报告 | 提交前用知网/维普自查，控制在 25% 以内 |

## 三、备选赛道：特色专项赛道 · 人工智能 OPC 专项

### 3.1 匹配度核查

| 大赛要求 | 本项目情况 | 匹配 |
|---|---|---|
| 核心主创仅 1 人 | 项目 1 人主导技术开发 | ✅ 完全匹配 |
| 团队 ≤15 人（核心主创之外可 2—14 人） | 可在保持"核心主创1人"前提下补团队 | ✅ |
| 负责人 ≤35 岁 | 符合 | ✅ |
| **不强制工商注册** | 未注册公司，无影响 | ✅ |
| 方向覆盖 AI 开发工具 / 教育等 | 本项目即"AI 开发工具 + 内容理解工具"，方向契合 | ✅ |
| 获奖如需推国赛按属性转标准赛道 | 若获奖可按"人工智能+"转高教主赛道推国赛 | ✅ 双保险 |

### 3.2 选择理由（与主赛道对比）

| 维度 | 高教主赛道 | AI OPC 专项 |
|---|---|---|
| 竞争烈度 | 高（全校/全省主力项目集中） | **低（省级首创赛道，报名者少，相对容易出线）** |
| 评审侧重 | 完整商业闭环、市场规模 | 技术能力 + AI 应用创新 + 核心主创个人能力 |
| 名额 | 金170/银380/铜550（面大） | 未单列名额（并入特色专项整体评奖，与五大赛道同级） |
| 团队要求 | 3—15人 | 核心主创 1 人即可 |
| 对 1 人主导项目友好度 | 一般（需补团队） | **高（规则天然适配）** |

### 3.3 决策建议

- **优先主报高教主赛道本科创意组**：获奖面大、政策叙事成熟、晋级通道清晰；
- **若校赛排序显示主赛道竞争过于激烈**，可切换 AI OPC 专项——本项目"1人核心主创 + AI 开发工具"与专项定义几乎一一对应，**在专项内属于"规则级适配"而非"勉强蹭线"**；
- 两条赛道材料可共用（技术文档、计划书、PPT 主体一致），仅需微调叙事重心（主赛道强调市场规模与商业模式；OPC 专项强调核心技术自主性与主创个人能力）。

## 四、不建议的赛道及原因

| 赛道 | 不建议原因 |
|---|---|
| 职教赛道 | 面向职业院校在校生，身份不符 |
| 萌芽赛道 | 面向普通高中在校生 |
| "青年红色筑梦之旅" | 需实际参加红旅活动并有乡村/红色实践成果，本项目无此基础；硬凑会被取消资格 |
| 产业赛道 | 需揭榜企业命题（8月15日命题截止），且成果转化组要求公司注册 ≤5年、师生股权 ≥51%，当前状态不满足 |
| 人形机器人专项 | 需实物机器人（双足直立、≥18关节等）与实物视频，与软件项目无关 |

## 六、风险提示

1. **查重红线**：计划书查重率必须 ≤25%，技术文档如大段引用本项目 README/AI 生成内容后未经改写，可能被判重复，提交前务必自查；
2. **一人参与限制**：负责人仅能参与 1 个赛道 1 个项目，报名前确认无重复报名；
3. **"十不准"红线**：不得外包代做、伪造数据、虚假陈述（附件9）——本项目为真实可运行系统，答辩时可现场演示，这是最大优势；
4. **教师角色**：指导教师不得作为团队成员参赛，仅可在指导栏列示。
