# 商业计划书
## 视界通（VideoInsight Agent）— 面向多平台视频的智能转写与结构化分析系统

> 参赛组别：中国国际大学生创新大赛（2026）高教主赛道 · 本科创意组 ·"人工智能+"类
> 版本：v1.0（提交版） | 编制日期：2026年8月

---

## 第一部分：项目概述

### 1.1 一句话介绍
视界通是一套面向中文互联网多平台视频的智能转写与结构化分析系统：用户提交视频链接或上传本地音视频文件，系统自动完成媒体下载、语音转写、智能分析与问答对话，把"不可检索的长视频"一键转化为"可读、可搜、可对话的结构化知识"。

### 1.2 项目定位
- **面向对象**：求职者（面试复盘/面经提取）、在线学习者（课程与讲座总结）、内容从业者（竞品与行业视频分析）、知识工作者（会议复盘）
- **核心价值**：将不可检索的视频内容，转化为可检索、可摘要、可问答的文本知识资产，显著降低视频信息获取的时间成本
- **Slogan**：让每一个长视频，三分钟读懂，随时可问

### 1.3 产品形态
Web 应用（SaaS 形态），前后端一体：用户上传文件或粘贴链接 → 系统输出 AI 总结 / 逐字稿 / 面试复盘 → 基于转写稿的 AI 多轮对话。

### 1.4 核心功能
1. 多平台视频链接分析：抖音、哔哩哔哩、小红书、快手（含自研解析方案）；
2. 本地音视频文件上传分析；
3. 三种分析模式：AI 智能总结、逐字稿提取、面试复盘（面经提取）；
4. 基于任务转写稿的 AI 多轮对话（支持用户自备模型与密钥，隐私零托管）；
5. 历史任务管理：AI 摘要命名、一键删除、多客户端数据隔离；
6. 沉浸式 Web 界面：深色/浅色双主题，任务进度实时动画。

## 第二部分：市场分析

### 2.1 市场背景
- 中文互联网视频内容爆发式增长：抖音日活跃用户已超 7 亿，哔哩哔哩月活跃用户超 3 亿，短视频与中长视频共同构成主流内容形态；
- 视频作为信息载体存在天然缺陷：**不可检索、不可摘要、不可对话**，用户在长视频中定位信息的时间成本极高；
- 大模型技术成熟（语音识别 + 大语言模型），使"视频→结构化知识"的自动化处理成本大幅下降，视频理解进入可产品化阶段。

### 2.2 目标市场与规模（TAM/SAM/SOM 框架）
| 层级 | 定义 | 规模估算 |
|---|---|---|
| TAM | 中国需要视频内容理解服务的互联网用户 | 数亿级（按短视频活跃用户规模估算） |
| SAM | 求职者 + 在线学习者 + 内容从业者 | 数千万级 |
| SOM | 初期可触达的付费用户（高校学生、求职培训学员等） | 10 万级 |

### 2.3 用户画像
1. **求职者（核心种子用户）**：海投面试、刷面经视频，需把口述面经变成可复习的结构化文档；
2. **考研/考证/网课学习者**：长课程视频需大纲、笔记与问答；
3. **新媒体运营/内容从业者**：竞品视频拆解、行业报告视频速读。

### 2.4 竞品分析
| 竞品/替代方案 | 优势 | 劣势 | 本项目差异点 |
|---|---|---|---|
| 平台自带总结（B站 AI 总结等） | 免安装、绑定平台 | 仅单平台、无对话、功能浅 | 多平台统一 + AI 对话 + 面经垂直场景 |
| 通用 AI 助手（豆包/Kimi/DeepSeek） | 通用对话能力强 | 无法解析视频本身 | 一体化全流程（下载→转写→分析→对话） |
| 付费转写工具（Notta、通义听悟等） | 成熟稳定 | 偏会议纪要，中文短视频平台支持弱 | 面向中文短视频平台 + 面试垂直场景 |
| 人工整理 | 准确 | 极慢、极贵 | 分钟级全自动 |

### 2.5 竞争壁垒
- **短期**：多平台解析能力（含快手自研解析器，填补通用工具空白）+ 完整工作流集成；
- **中期**：垂直场景数据积累（面经库、课程知识库）→ 场景化提示词与评测基准；
- **长期**：用户内容资产沉淀（个人知识库）带来的迁移成本。

## 第三部分：产品与技术

### 3.1 系统架构
分层架构：前端（Web 沉浸式界面）→ API 层（FastAPI，RESTful）→ 工作流编排层（下载→转写→分析→标题生成）→ 适配器层（下载器/音频/ASR/LLM，Mock 与真实双实现）→ 存储层（SQLite 任务库 + JSON 结果 + 媒体文件）。

### 3.2 关键技术
1. **多平台媒体获取**：抖音/B站/小红书走 yt-dlp；快手走自研分享页解析器（解析 `mainMvUrls` 字段获取 mp4 直链）；
2. **语音转写**：阿里云 DashScope Paraformer 非流式 ASR，输出带时间戳的分段结果；
3. **大模型分析**：OpenAI 兼容接口（DeepSeek/OpenAI 均可），三种分析模式 + 提示词硬性兜底规则（防幻觉、防噪音）；
4. **双链路架构**：下载/ASR/LLM 三环节均为"Mock/真实"双实现，无 Key 可完整演示，有 Key 即真实，极大降低落地门槛；
5. **用户自备模型**：对话接口支持请求级携带用户自己的 provider/base_url/model/api_key，平台不持有任何用户密钥；
6. **多用户隔离**：浏览器持久化 client_id + 服务端归属校验，任务列表/详情/删除/对话/媒体均限本人访问，无需账号体系。

### 3.3 技术成熟度
系统已完整实现并通过端到端验证（Mock 全流程、真实 ASR/LLM 链路、多客户端隔离、数据库自动迁移），达到**可演示、可试用**的原型级成熟度。

## 第四部分：商业模式

### 4.1 商业模式画布
| 模块 | 内容 |
|---|---|
| 价值主张 | 视频 → 结构化知识 + 自由问答，多平台一站式 |
| 客户细分 | 求职者 / 学习者 / 内容从业者 / 机构 |
| 渠道 | 高校社团、求职社区（牛客/应届生）、小红书/B站内容营销、机构合作 |
| 收入来源 | 订阅制 + 用量包 + 机构定制 |
| 关键资源 | 多平台解析能力、场景化提示词、ASR/LLM 通道 |
| 关键活动 | 功能迭代、内容营销、校园推广 |
| 关键伙伴 | 求职培训机构、高校就业指导中心、云服务商 |
| 成本结构 | 服务器、ASR/LLM 调用费（用户自备模型模式可转移）、推广 |
| 客户关系 | 自助服务 + 社区 + 工单 |

### 4.2 收入模式
1. **免费版**：每日限量分析，体验完整链路；
2. **订阅版（主模式）**：月/年订阅，按分析时长包；
3. **用量包**：按次/按时长购买，满足低频用户；
4. **用户自备模型模式**：用户自带 Key，平台只收服务费——**边际成本趋近于零**，区别于竞品的独特商业模式；
5. **机构版**：培训机构/高校批量授权 + 私有化部署。

### 4.3 定价方案
| 版本 | 价格 | 权益 |
|---|---|---|
| 免费版 | ¥0 | 每日 3 次分析 |
| 个人版 | ¥19.9/月（或 ¥199/年） | 不限次数 + AI 对话 + 历史管理 |
| 专业版 | ¥39.9/月 | 长视频 + 批量分析 + 面经模板 |
| 机构版 | 按年洽谈 | 私有化部署 + 账号管理 + 定制化 |

## 第五部分：营销与推广

### 5.1 冷启动策略
1. **高校渠道**：校园双创社群、就业指导中心合作，以"面经提取"作为考研/求职季刚需场景切入；
2. **内容营销**：在小红书/B站发布"面试视频一键转面经笔记"演示内容（产品能力即广告）；
3. **种子用户计划**：前 100 名用户免费一年，换取反馈与案例背书。

### 5.2 增长路径
- 第一阶段（0-1）：高校求职场景验证，目标 1000 活跃用户；
- 第二阶段（1-10）：扩展学习/内容从业场景，签约 2-3 家机构；
- 第三阶段：机构版与私有化部署，进入 B 端市场。
