## 第一部分：项目概述

### 1.1 一句话介绍
【用一句话说明产品】：VideoInsight Agent 是一套把"抖音/B站/小红书/快手等平台的长视频"一键变成"可读、可搜、可对话的结构化知识"的 AI 工具。

### 1.2 项目定位
- **面向对象**：求职者（面经提取）、学习者（课程/技术分享总结）、内容从业者（竞品/行业视频分析）、知识工作者（会议/讲座复盘）
- **核心价值**：把不可检索的视频，转化为可检索、可摘要、可问答的文本知识资产
- **Slogan 备选**："视频不留声，知识可对话" / "让每一个长视频，三分钟读懂，随时可问"

### 1.3 产品形态
Web 应用（SaaS 形态），用户上传视频/粘贴链接 → 系统输出结构化分析 + AI 对话。

## 第二部分：市场分析

### 2.1 市场背景
- 中文互联网视频内容爆发式增长：抖音日活【待填，可引用公开数据，如"抖音日活跃用户超 7 亿"】；B站【待填】；
- 视频信息不可检索、不可摘要 → "视频理解"需求成为 AI 时代刚需；
- 大模型成熟（ASR + LLM），使"视频→结构化知识"的技术成本大幅下降。

### 2.2 目标市场与规模（TAM/SAM/SOM 框架）
| 层级 | 定义 | 规模估算【待填，需调研引用】 |
|---|---|---|
| TAM | 全部需要视频内容理解的中国互联网用户 | 【待填】 |
| SAM | 求职者 + 在线学习者 + 内容从业者 | 【待填】 |
| SOM | 可触达的早期付费用户（高校学生、求职培训学员等） | 【待填】 |

### 2.3 用户画像
1. **求职者（核心种子用户）**：海投面试、刷面经视频，需要把"口述面经"变成可复习的结构化文档；
2. **考研/考证/网课学习者**：长课程视频，需要大纲 + 笔记 + 问答；
3. **新媒体/运营**：竞品视频拆解、行业报告视频速读。

### 2.4 竞品分析
| 竞品/替代方案 | 优势 | 劣势 | 本项目差异点 |
|---|---|---|---|
| 平台自带总结（B站 AI 总结、抖音等） | 免安装、绑定平台 | 仅单平台、无对话、功能浅 | 多平台统一 + AI 对话 + 面经垂直场景 |
| 通用 AI 助手（豆包/Kimi/DeepSeek） | 通用对话 | 无法解析视频本身，需用户自行转写 | 一体化全流程（下载→转写→分析→对话） |
| 付费工具（Notta、通义听悟等） | 成熟、稳定 | 主要面向会议纪要，中文多平台视频支持弱 | 面向中文短视频平台 + 面试垂直场景 |
| 人工整理 | 准确 | 极慢、极贵 | 分钟级全自动 |

### 2.5 竞争壁垒分析
- **多平台解析能力**（含快手自研解析器）与**完整工作流集成**是当前差异化点；
- 中期壁垒：垂直场景数据积累（面经库、课程知识库）→ 形成场景化 Prompt 与评测基准；
- 长期壁垒：用户内容资产沉淀（个人知识库）带来的迁移成本。

## 第三部分：产品与技术

### 3.1 产品功能
- 多平台链接分析 / 本地文件上传；
- 三种分析模式：AI 总结、逐字稿、面试复盘（面经提取）；
- 基于转写稿的 AI 多轮对话；
- 历史任务管理（AI 摘要命名、一键删除）；
- 用户自备模型（隐私友好）、深/浅主题、Cookies 管理。

### 3.2 技术要点（详见《01-技术文档.md》）
- FastAPI + SQLite + 原生前端，单机可部署；
- 适配器模式：下载 / ASR / LLM 三环节 Mock-真实双链路；
- 快手自研解析器、DashScope Paraformer ASR、OpenAI 兼容 LLM；
- 多客户端数据隔离（client_id）、用户密钥零托管。

### 3.3 技术成熟度（TRL 对标）
- 系统已完整实现并通过端到端验证，达到**可演示、可试用的原型级**（对标 TRL 6 左右）；
- 待商业化补充：账号体系、配额计费、并发扩容（队列）、合规审核。

## 第四部分：商业模式

### 4.1 商业模式画布（简述）
| 模块 | 内容 |
|---|---|
| 价值主张 | 视频 → 结构化知识 + 自由问答，多平台一站式 |
| 客户细分 | 求职者 / 学习者 / 内容从业者 / 机构 |
| 渠道 | 高校社团推广、求职社区（牛客/应届生）、小红书/B站内容营销、机构合作 |
| 收入来源 | 订阅制 + 用量包 + 机构定制 |
| 关键资源 | 多平台解析能力、场景化 Prompt、ASR/LLM 通道 |
| 关键活动 | 功能迭代、内容营销、校园推广 |
| 关键伙伴 | 求职培训机构、高校就业指导中心、云服务商 |
| 成本结构 | 服务器、ASR/LLM 调用费（可用"用户自备模型"模式转移）、推广 |
| 客户关系 | 自助服务 + 社区 + 工单 |

### 4.2 收入模式设计
1. **免费版**：每日限量分析次数（体验链路，Mock/低配模型）；
2. **订阅版（推荐主模式）**：月/年订阅，按分析时长包（如每月 300 分钟视频）；
3. **用量包**：按次/按时长购买；
4. **用户自备模型模式**：高级用户自带 Key，平台只收服务费——**边际成本趋近于零**，这是本项目区别于竞品的独特商业模式；
5. **机构版**：求职培训机构/高校批量授权 + 私有化部署。

## 第五部分：营销与推广

### 5.1 冷启动策略
1. **高校渠道**：校园双创社群、就业指导中心合作，把"面经提取"作为考研/求职季刚需场景切入；
2. **内容营销**：在小红书/B站发布"面试视频一键转面经笔记"演示内容（这本身就是本项目能力的展示）；
3. **种子用户计划**：前 100 名用户免费一年，换取反馈与案例。

### 5.2 增长路径
- 第一阶段（0-1）：高校求职场景验证 → 1000 活跃用户；
- 第二阶段（1-10）：扩展学习/内容从业场景，机构合作；
- 第三阶段：机构版与私有化部署，进入 B 端。
