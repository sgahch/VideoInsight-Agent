# 网评 PPT 大纲（15 分钟路演版）
## VideoInsight Agent — 面向多平台视频的智能转写与结构化分析系统

> 用途：中国国际大学生创新大赛（2026）高教主赛道 · 本科创意组 · 网评/现场路演
> 结构：20 页，按"痛点→方案→技术→验证→商业→团队→规划"黄金叙事线
> 每页含【页面标题】【核心文案要点】【视觉/演示建议】【讲稿提示】

---

### P1 · 封面
- **标题**：VideoInsight Agent — 面向多平台视频的智能转写与结构化分析系统
- **副标题**：我敢闯，我会创 · 中国国际大学生创新大赛（2026）
- **信息**：参赛组别（高教主赛道·本科创意组·"人工智能+"）、团队名、日期
- 视觉：产品截图做背景，暗色沉浸式风格呼应产品主题

### P2 · 痛点：视频时代的信息焦虑
- 核心：**视频不可检索、不可摘要、不可对话**
- 三个数据/场景：
  - 求职者刷 50 条面经视频，手工整理 3 小时（画面：凌乱的笔记）
  - 网课 2 小时，找不到核心知识点（画面：进度条上反复拖拽）
  - 内容从业者分析竞品视频，逐条人工转写
- 讲稿：把问题具象化，"你是否有过把视频反复拖拽找重点的经历？"

### P3 · 解决方案总览：一条流水线
- 一句话：**提交链接或文件 → 系统自动输出结构化知识 + AI 对话**
- 流程图（下载→转写→分析→对话四步）或产品首页截图
- 三种输出：AI 总结 / 逐字稿 / 面试复盘；加 AI 对话

### P4 · 产品演示（现场/录屏 60-90 秒）★核心页
- 演示 1：粘贴一个视频链接 → 任务进度 0→100% → 生成"一句话核心+大纲+要点+建议"
- 演示 2：切到"面试复盘"模式 → 输出岗位/问题/回答要点
- 演示 3：AI 对话追问"第二部分的观点是什么" → 基于转写稿回答
- 讲稿：演示前先说"下面我用真实系统演示，不是动画"，这是评审信任度关键

### P5 · 市场空间
- 背景：短视频/长视频内容爆发，视频理解是 AI 时代刚需
- TAM/SAM/SOM 金字塔图【数据待填，引用公开来源】
- 三个核心客群：求职者 / 学习者 / 内容从业者

### P6 · 竞品对比：我们不一样
- 对比表（四列）：平台自带总结 / 通用 AI 助手 / 付费转写工具 / VideoInsight
- 差异点高亮：**多平台统一 + 结构化面经场景 + 自由对话 + 用户自备模型**
- 结论句：不是"又一个转写工具"，而是"视频知识结构化 + 场景化问答"

### P7 · 技术架构总览
- 分层架构图：前端 / API 层 / 工作流编排 / 适配器层（下载/音频/ASR/LLM）/ 存储层
- 关键：适配器模式 → Mock 与真实链路可切换
- 讲稿：强调"工程完整性"，不是 demo 是系统

### P8 · 核心技术点 1：多平台解析
- 抖音/B站/小红书（yt-dlp）+ **快手自研解析器**（填补 yt-dlp 空白）
- 无 cookies 匿名下载多数公开视频；cookies 兜底复杂场景
- 视觉：四平台 logo + 解析流程示意

### P9 · 核心技术点 2：双链路架构（Mock/真实）
- 同一接口，两种实现：无 Key 可演示，有 Key 即真实
- 价值：**落地门槛低、教学演示友好、评审可现场验证**
- 视觉：接口抽象示意图（Downloader/Transcriber/Analyzer）

### P10 · 核心技术点 3：AI 对话 + 用户自备模型
- 基于转写稿的上下文对话（不引入外部知识，防幻觉）
- **用户自带 Key**：密钥零托管，对话成本用户自担 → 多用户商业化的关键设计
- 视觉：对话界面截图 + 模型设置界面截图

### P11 · 核心技术点 4：工程化能力
- 任务状态机 + 持久化（SQLite + 结果落盘）
- 多客户端数据隔离（client_id）：**无需账号体系即多用户隔离**
- AI 摘要任务命名、自动数据库迁移、级联清理
- 视觉：历史任务列表截图（AI 命名的任务名）

### P12 · 创新点总结（4 个"人无我有"）
1. 快手自研解析器，多平台统一理解
2. Mock/真实双链路，零依赖可演示
3. 用户自备模型，密钥零托管商业模式
4. 轻量多用户隔离，无需账号体系

### P13 · 验证与测试
- 自动化测试覆盖（API/工作流/存储/下载/提示词）
- 实测记录：端到端 mock 链路、真实 DeepSeek 对话、多客户端隔离、老库迁移
- 强调：**系统真实可运行，答辩可现场演示**

### P14 · 商业模式
- 收入四层：免费版（引流）/ 订阅版（主收入）/ 用量包 / 机构版（私有化）
- 独特点：**用户自备模型模式 → 平台边际成本趋近于零**
- 视觉：定价表 + 商业模式画布简化图

### P15 · 财务预测（3 年）【待填】
- 成本结构：服务器 / ASR / LLM（可转移）
- 收入预测：用户数 → 付费率 → 收入 3 年曲线图
- 讲稿：突出"轻资产、高毛利、成本可转移"

### P16 · 营销与冷启动
- 高校渠道：就业指导中心 / 双创社群（面经场景天然契合）
- 内容营销：在小红书/B站发"面试视频一键转面经笔记"（自身能力即广告）
- 种子计划：前 100 用户免费一年换反馈

### P17 · 团队介绍
- 团队合照/头像 + 分工表【待填，≥3人】
- 负责人：全栈开发（真实交付了可运行系统——这是最强背书）
- 指导教师【待填】

### P18 · 风险与应对
- 合规（平台下载）：主推上传链路，链接解析为技术能力
- 版权/内容安全：面向私有内容 + 规划审核能力
- 竞争：深耕垂直场景（面试/学习）做深做透
- 技术依赖：适配器架构多供应商可切换

### P19 · 发展规划
- 0-6月：公测 + 1000 用户；6-18月：付费 + 机构合作；18-36月：垂直头部
- 二期功能：异步队列、内容安全、多模态、飞书机器人

## PPT 制作与提交注意事项（对照大赛要求）

1. **查重**：PPT 文本导出查重，连同商业计划书 ≤25%；
2. **篇幅**：控制在 20 页内，每页 ≤30 字正文（讲稿在备注页）；
3. **现场演示**：务必提前准备：本机/虚拟机环境 + 网络 + 备用 Key；建议把 Mock 链路作为兜底（无网络也能演示）；
4. **命名**：按校赛/省赛要求命名（如"XX大学-项目名-网评PPT"）；
5. **一页一观点**：评审 15 分钟看 20 页，每页只讲一件事。
